# Датасет (этап 2)

На первом этапе датасет не создавался. Примеры из предыдущего проекта не следует автоматически считать размеченными обучающими данными.

Планируемые метки: `contract`, `invoice`, `act`, `application`, `memo`, `report`.
Для обучения, валидации и теста следует использовать отдельные выборки без дубликатов и утечек между шаблонами.
